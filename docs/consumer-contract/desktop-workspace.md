# 데스크톱 작업 영역 계약

ResizableSplitPane은 데스크톱의 primary/secondary 영역과 `role="separator"` 경계만 제공한다. `size`는 px 숫자로 bind하고, 생략하면 `defaultSize`(기본값 280)를 최초 크기로 사용한다. 명시한 `size`와 사용자 조작 값은 이후 `defaultSize` 변경으로 덮어쓰지 않으며, double-click으로 복원할 때는 현재 `defaultSize`를 사용한다. 기본 최소 220, 기본 최대 480을 사용한다. 글자 크기나 문장 길이로 primary 폭을 다시 계산하지 않으며, 긴 탐색 라벨의 말줄임과 내부 scroll은 소비 콘텐츠가 정한다. 경계선은 1px token으로 보이지만 기본 pointer hit area는 24px이고 Pointer Events capture, cancel/lost-capture cleanup, drag 중에만 적용되는 `.zdp-user-select-dragging`, Arrow/Home/End/PageUp/PageDown, Shift 가속, RTL 방향, double-click 기본 폭 복귀를 제공한다. 경계의 앞/뒤 절반을 한 번 클릭하면 한 step 이동하므로 drag가 어려운 pointer 사용자도 폭을 바꿀 수 있다.

`createZdpSplitPaneController({ root, primary, separator, secondary }, options)`는 같은 Pointer Events, keyboard, RTL, ResizeObserver clamp, class, CSS variable, `role="separator"`, `aria-orientation`, `aria-valuemin/max/now/text` 계약을 일반 DOM에 연결한다. 드래그 크기는 separator hit target 안에서 누른 위치와 무관하게 drag-start size에 실제 pointer delta만 더하므로 경계 양끝에서 잡아도 첫 이동에 크기가 튀지 않는다. drag-start에서 방향을 한 번 측정하고 pointer move는 animation frame당 한 번만 반영하며, pointer capture가 실패하거나 진행 중 orientation이 바뀌면 drag와 text-selection lock을 즉시 취소하고 혼합 축 값을 commit하지 않는다. Svelte binding이 controller의 내부 size를 그대로 되돌려 주는 update는 재측정·재렌더하지 않는다. Astro와 정적 HTML은 package root가 아니라 `zdp-design-system/split-pane`에서 import해 Svelte component barrel을 Vite dev dependency graph에 넣지 않는다. import 자체는 SSR-safe이며 DOM 조회와 controller 생성은 브라우저 lifecycle에서만 수행한다. `update()`는 viewport 또는 container 조건이 바뀔 때 크기와 disabled 상태를 동기화하고, `destroy()`는 pointer capture, pending animation frame, observer, event listener, 임시 text-selection 상태와 controller가 바꾼 DOM 속성을 정리한다. Astro와 정적 HTML 소비처는 Svelte 컴포넌트 동작을 복제하지 않고 이 controller와 shared CSS를 쓴다.

`createZdpSplitPaneSizePersistence({ key })`는 versioned localStorage key, 숫자 검증, 220–480 clamp, 저장소 예외 처리만 제공한다. helper 생성은 SSR-safe이고 `load`/`save` 호출은 소비 앱이 `onMount`와 `onResizeCommit`에서 명시적으로 연결한다. 컴포넌트 안에는 숨은 저장이나 전역 layout state가 없다. `secondaryMinSize`는 부모 컨테이너에서 남겨야 할 공간을 선언하며, 둘을 동시에 만족할 수 없는 폭에서는 `data-zdp-resizable-split-pane-constrained="true"`가 표시된다. 이 상태를 모바일 layout으로 버티게 하지 말고 소비 앱의 container/media 조건에서 split pane을 제거하고 `Sheet placement="left"` 또는 접힘 메뉴로 교체한다.

상위 개요와 금지 경계는 [docs/CONSUMER_CONTRACT.md](../CONSUMER_CONTRACT.md)를 따른다.
